Feature Engineering Applied

  • Standardization: StandardScaler applied to numerical features for consistent scaling
  • One-Hot Encoding: Categorical variables converted to binary features with handle_unknown='ignore'

Cost Estimation API

Endpoint

POST /estimate_cost Content-Type: application/x-www-form-urlencoded

Required Parameters

  • inflation_factor (float): Economic inflation adjustment factor (range: 1.00 - 1.34)
  • official_budget_range (string): Budget category (e.g., "$3M-$6M", "Less than 1M")
  • ciqs_complexity_category (string): CIQS complexity rating (Category 1-4)
  • cnt_division (integer): Construction division code (range: 1.00 - 29.00)
  • cnt_item_code (integer): Construction item code (range: 1.00 - 61.00)
  • county_name (string): County where project is located
  • area_type (string): Urban or Rural designation
  • acf (float): Area Cost Factor (range: 0.80 - 1.19)
  • project_type (string): Type of construction project
  • project_category (string): General project category
  • project_state (string): US state abbreviation
  • region (string): Geographic region (Region_0 to Region_3)

Response Format

{ "success": true, "estimated_cost": 4358432.11, "estimated_cost_formatted": "$4,358,432.11", "confidence_interval": { "lower": 3268824.08, "upper": 5448040.14, "lower_formatted": "$3,268,824.08", "upper_formatted": "$5,448,040.14" }, "similar_projects": { "count": 6147, "avg_cost_formatted": "$1,310,815.37", "median_cost_formatted": "$856,470.56", "min_cost_formatted": "$106,090.18", "max_cost_formatted": "$5,753,308.45" }, "timestamp": "2025-11-25 14:30:22" }

Example cURL Request

curl -X POST http://localhost:5000/estimate_cost \ -d "inflation_factor=1.05" \ -d "official_budget_range=$3M-$6M" \ -d "ciqs_complexity_category=Category 4" \ -d "cnt_division=6" \ -d "cnt_item_code=6" \ -d "county_name=Alcona County" \ -d "area_type=Rural" \ -d "acf=1.01" \ -d "project_type=Pavement Markers" \ -d "project_category=Civil" \ -d "project_state=MI" \ -d "region=Region_3"

Using the Cost Estimator

Step 1: Navigate to Cost Estimator

Click on "Cost Estimator" in the navigation bar to access the estimation form.

Step 2: Fill in Project Details

Provide information about your construction project. All fields marked with * are required:

  • Project Type: Select the specific type of construction work (e.g., Pavement Markers, Sidewalks)
  • Budget Range: Choose the official budget category for the project
  • Complexity: Select CIQS complexity rating (higher = more complex)
  • Location: Provide state, county, and area type (urban/rural)
  • Economic Factors: Enter inflation factor and area cost factor
  • Construction Codes: Specify division and item codes

Step 3: Calculate Estimate

Click the "Calculate Cost Estimate" button. The system will:

  • Process your inputs through the trained Random Forest model
  • Generate a cost prediction with ±25% confidence interval
  • Find similar projects in the database for comparison
  • Display results with detailed breakdown

Step 4: Interpreting Results

  • Estimated Cost: The ML model's prediction for your project (2025 normalized dollars)
  • Confidence Range: ±25% range accounting for uncertainty and project variability
  • Similar Projects: Statistics from comparable projects matching your criteria
  • Input Summary: Review of all parameters used in the prediction
💡 Pro Tip: The model works best when you have accurate values for all fields. If unsure, use the median values provided as guidance.

Model Limitations & Considerations

  • Class 5 Estimates Only: This model provides early-stage, conceptual estimates (±25% accuracy). Not suitable for detailed bidding or final cost estimates.
  • Normalized Costs: All predictions are in 2025 normalized dollars. Adjust for future years using appropriate inflation factors.
  • Historical Data: Model trained on projects from 2010-2025. May not capture unprecedented market conditions or novel construction methods.
  • Geographic Coverage: Best performance on projects in states well-represented in training data.
  • Project Scope: Designed for typical construction projects. Highly unique or complex projects may have larger prediction errors.
  • No Real-Time Updates: Model must be retrained periodically to incorporate new market trends and inflation data.
📌 Important: Always validate estimates with subject matter experts and adjust for project-specific factors not captured by the model.
